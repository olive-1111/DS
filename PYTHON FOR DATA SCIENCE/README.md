# Python for Data Science: Comprehensive 17-Hour Certification

This folder contains a deep-dive into the Data Science lifecycle using Python. It is organized into 10 distinct segments, documenting my transition from data manipulation basics to Machine Learning and Text Classification.

## REPOSITORY STRUCTURE

This project is divided into specialized segments to reflect the detailed progression of the course:
1. **Intro to Pandas & NumPy**
2. **Filtering Data**
3. **Data Extraction**
4. **Reshaping & Pivoting**
5. **Project #1: Data Visualizations**
6. **GroupBy & Aggregation**
7. **Merging & Concatenating**
8. **Regular Expressions (RegEx)**
9. **Project #2: Data Cleaning**
10. **Machine Learning & Text Classification**

## WHAT I LEARNT

* **Library Mastery:** Hands-on experience with **Pandas**, **NumPy**, and **scikit-learn**.
* **Visual Precision:** Mastering the logic required to render visualizations correctly in Jupyter; learning that even a tiny syntax difference can prevent a chart from displaying.
* **Text Mining:** Learning the logic of **Regular Expressions** and applying them to **Text Classification** projects.
* **Meticulous Coding:** Developed a disciplined approach to typing complex, multi-layered commands where one character determines success or failure.

## OBSERVATIONS & DISCREPANCIES

* **Web Scraping Limitations:** Despite extensive troubleshooting, the web scraping segment could not be completed due to the source URLs being disbanded/offline.
* **Pathing Logic:** Learned the specific "summoning" tricks required to load data into Jupyter when standard paths fail.

## CHALLENGES

* **Hardware & Processing:** Managing an older laptop made processing heavy files and rendering graphs a test of patience and resource management.
* **Complexity Fatigue:** Facing "speechless" moments when confronted with entirely new and strange command structures.
* **Visual Logic:** Navigating the specific steps needed to "call" a visualization and ensure it renders within the notebook environment.

## SOLUTIONS

* **"Dirty Hands" Philosophy:** Prioritized constant practice over perfection, manually typing every command to build muscle memory regardless of complexity.
* **AI-Assisted Troubleshooting:** Leveraged AI to learn advanced data "summoning" and to diagnose connection errors when external websites failed.
* **Strategic Patience:** Stayed committed to the process even when code execution took longer than expected or required multiple manual corrections to match the tutorial.
