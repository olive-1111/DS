# Python for Data Science: EDA, A/B Testing & Business Intelligence

This project focuses on the practical application of Python in a business environment. It covers the full spectrum of data analytics, from exploratory analysis and preprocessing to complex A/B testing and customer segmentation.

## WHAT I LEARNT

* **Data Exploration & Preprocessing:** Mastering the filtering, sorting, and grouping of complex datasets.
* **Descriptive Statistics:** Using Python to calculate and interpret the statistical "story" of the data.
* **A/B Testing (Theory & Practice):** Setting up Experimental vs. Control groups, understanding statistical significance, and concluding results.
* **Superstore Data Analytics:** Performing customer segmentation, geographic market analysis, and tracking sales trends.
* **Meticulous Visualization:** Developing the discipline to handle complex Jupyter commands where one character determines if a chart renders or fails.

## OBSERVATIONS & DISCREPANCIES

* **Statistical Logic:** Observed that concluding A/B tests requires a deeper understanding of "Statistical Significance" compared to standard data reporting.
* **File Management:** Learned to distinguish between core `.ipynb` work files and system-generated checkpoint files to maintain a clean development environment.

## CHALLENGES

* **Complex Theory:** The A/B Test logic introduced theoretical concepts that were entirely new and required intense focus to implement correctly.
* **Hardware & Processing:** Managing an older laptop made processing heavy files and rendering high-detail graphs a test of patience.
* **Syntax Precision:** Faced "speechless" moments with complex commands, requiring multiple manual corrections to avoid errors.

## SOLUTIONS

* **The "Meticulous" Mindset:** Learned to be extremely careful with every bracket and comma, as even a tiny difference could break the logic of a statistical test.
* **Strategic Patience:** Stayed committed to the process during slow execution times, ensuring that each visualization was rendered perfectly before moving to the next segment.
* **AI-Guided Analysis:** Used AI to clarify complex statistical outputs like P-values and Confidence Intervals when the tutorial moved quickly.
