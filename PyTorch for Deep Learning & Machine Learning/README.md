# PyTorch for Deep Learning & Machine Learning: A Survival Journey

This repository documents an intensive deep-dive into Neural Networks and Computer Vision. Completed on hardware with significant resource limitations, this project represents a mastery of both Deep Learning theory and the professional grit required to succeed in high-pressure technical environments.

## THE "HARDWARE SURVIVAL" EXPERIENCE

Running 2022-era Deep Learning models on legacy hardware in 2025 presented extreme technical and physical challenges:

* **System Stability Anxiety:** Navigating the high-stress environment of frequent "system hangs," kernel crashes, and black-screen freezes that required manual hardware power-cycles.
* **Bridge-Building (2022 to 2025):** Developed an "intimate" collaborative relationship with AI to translate and update 2022 tutorial commands into 2025-compatible code, ensuring project viability despite version shifts.
* **Intuition-Based Computing:** Developed a "system-intuition" to detect "dangerous" commands before execution. I learned to manually downscale **Epoch counts** and batch sizes to prevent hardware failure.

## CHALLENGES & DISCREPANCIES

* **Extraterrestrial Complexity:** Managing "super long" command strings (40+ lines per cell) that pushed the limits of mental endurance and syntax precision.
* **The Error Loop:** Encountered persistent errors where standard fixes failed, requiring hundreds of manual iterations and a high-level of physical and mental persistence.
* **Resource Exhaustion:** Certain advanced commands proved hazardous for the local CPU/RAM, leading to strategic pivots to preserve system health while maintaining learning momentum.

## SOLUTIONS

* **Professional Grit:** Maintained a disciplined learning pace despite the physical toll of long-duration troubleshooting and hardware-related stress.
* **Strategic Optimization:** Manually scaled down model parameters to allow training loops to execute without crashing the OS.
* **AI-Integrated Debugging:** Utilized AI as a real-time bridge to solve "extraterrestrial" syntax errors and hardware-specific glitches that the tutorial did not cover.
