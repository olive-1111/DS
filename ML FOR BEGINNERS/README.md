# Machine Learning: Foundations & Neural Architectures

This repository contains a comprehensive exploration of Machine Learning paradigms, spanning from classical statistical methods (KNN, Naive Bayes, SVM) to modern Deep Learning using TensorFlow.

##  PROJECT ECOSYSTEM

### **1. Supervised Learning (Classification & Regression)**
* **Statistical Models:** Implementation of **K-Nearest Neighbors (KNN)**, **Naive Bayes**, and **Support Vector Machines (SVM)** to categorize complex data points.
* **Linear & Logistic Regression:** Developed custom implementations to understand the mathematical "bridge" between simple statistics and predictive modeling.
* **Refactored Housing Predictor:** Successfully migrated legacy code to modern datasets, ensuring correct feature mapping and model validation.

### **2. Deep Learning & Neural Networks**
* **TensorFlow Integration:** Transitioned from Scikit-Learn to **TensorFlow/Keras** for advanced Neural Network construction.
* **The "Neuron" Logic:** Implemented Linear Regression using a single-neuron architecture to understand the atomic unit of Artificial Intelligence.
* **Classification & Regression NNs:** Built and trained multi-layer perceptrons to handle both categorical and continuous data.

### **3. Unsupervised Learning**
* **Clustering:** Implemented **K-Means Clustering** to identify hidden structures within unlabeled datasets.
* **Dimensionality Reduction:** Utilized **Principal Component Analysis (PCA)** to compress high-dimensional data while maintaining statistical variance.

## THE LEARNING JOURNEY & CHALLENGES

* **Tutorial Refactoring:** Navigated the technical gap between 2021 tutorials and modern 2026 library requirements.
* **Logic Over Syntax:** While the commands felt "foreign" initially, I prioritized understanding the **Data Flow**—how raw data is prepared, split, and fed into an algorithm to produce a visualization.
* **Visualization Fascinations:** Beyond the math, I focused on plotting decision boundaries and loss curves to see the "brain" of the model working in real-time.

## TECHNICAL STACK
* **Frameworks:** TensorFlow, Scikit-Learn
* **Analysis:** Pandas, NumPy
* **Visualization:** Matplotlib, Seaborn
